# Security & Acceptable Use

dsh-stavros is an **authorized-only** red-team / penetration-testing assistant.

- Use it **only** against systems you own or for which you hold **explicit written
  authorization** (a signed engagement, an in-scope bug-bounty program, or a lab you control).
- The scope guard is **fail-closed**: with no `scope.json`, or an empty one, every
  target action is denied. Do not disable or bypass it.
- Unauthorized access to computer systems is illegal in most jurisdictions. You are
  solely responsible for your use of this software.

## Reporting a vulnerability in this project

Open a GitHub issue for non-sensitive reports, or contact the maintainer for
anything sensitive. Please do not include third-party engagement data in reports.
