# skills/ — playbook e conoscenza del preset stavros

In Fase 1 qui confluiscono:
- `playbook-stavros` (da `knowledge.md`: metodologia OWASP-aligned, rules of engagement);
- skills per sottodominio (recon, mapping, injection, auth, wireless, host/C2…);
- `refs/` (knowledge base per classe, portata da `tools/payloads/` e `docs/refs/`).

Convenzione (da dsh-redteam-model): skills = istruzioni operative caricabili via `tool-skill`;
refs = knowledge base con indice `README.md` e zero path locali.
